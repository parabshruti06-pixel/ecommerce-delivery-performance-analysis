# E-Commerce Delivery Performance Analysis | MySQL

## Project Overview
This project analyzes e-commerce delivery performance using MySQL to identify late-delivery patterns, customer rating differences, and seller performance issues.

## Business Objectives
- Measure the percentage of orders delivered late.
- Compare customer ratings for late and on-time deliveries.
- Identify high-revenue sellers with elevated late-delivery rates.
- Generate insights to support delivery and seller performance improvement.

## Tools & Technologies
- MySQL
- SQL Joins
- Common Table Expressions (CTEs)
- Window Functions
- RANK() and LAG()

## Dataset
The analysis covers approximately 99,441 orders across seven tables.

## Key Findings
- Approximately 8.11% of orders were delivered late.
- Average customer rating was 2.57 for late deliveries versus 4.29 for on-time deliveries.
- Identified 131 high-revenue sellers with late-delivery rates above 10%.

## Business Value
The findings can help e-commerce businesses investigate delivery delays, improve customer satisfaction, and monitor seller performance.
